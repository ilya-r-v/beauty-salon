# Салон красоты — КР1 (Java, консоль)

Консольная информационная система салона красоты: клиенты, мастера, услуги
и записи на услугу (основная сущность). Данные хранятся в PostgreSQL,
доступ — через JDBC, архитектура разложена по слоям.

## Как запустить

1. Установите PostgreSQL, создайте базу: `createdb beauty_salon`
2. Выполните схему: `psql -d beauty_salon -f src/main/resources/schema.sql`
3. При необходимости поправьте логин/пароль в `util/DatabaseManager.java`
4. Соберите проект: `mvn clean package`
5. Запустите: `java -jar target/beauty-salon.jar`
   (или запустите `Main.java` из IDE — IntelliJ IDEA сама подтянет
   зависимости из `pom.xml`)

## Что реализовано по пунктам меню

1. **Клиенты и мастера** — создание/просмотр/изменение/удаление клиента,
   назначение клиента мастером (создаёт `master_profile`), список мастеров
2. **Услуги** — типы услуг, услуги (привязка к мастеру и типу), варианты
   услуг с ценой; создание и удаление на каждом уровне
3. **Записи на услугу** — полный CRUD, смена статуса с проверкой допустимых
   переходов
4. **Поиск** — по имени клиента, названию услуги (для записей); по имени и
   телефону (для клиентов); по названию (для услуг)
5. **Фильтрация** — по статусу, мастеру, диапазону дат (записи); по мастеру,
   типу (услуги); по диапазону цен (варианты)
6. **Статистика** — количество клиентов, мастеров, записей по каждому
   статусу, суммарная выручка по завершённым записям (5+ показателей)
7. **Экспорт данных** — выгрузка всех записей на услугу в `.xlsx` с
   человекочитаемыми именами клиента и услуги (Apache POI)
8. **Таблицы базы данных** — список таблиц через `information_schema.tables`

## Бизнес-правила

**Записи на услугу (`BookingService`):**
1. Нельзя создать запись с несуществующим клиентом
2. Нельзя создать запись с несуществующим мастером
3. Нельзя создать запись на прошедшее время
4. Нельзя создать запись, если мастер уже занят на это время
5. Разрешены только переходы `PENDING → CONFIRMED → COMPLETED` и `→ CANCELLED`
   из `PENDING`/`CONFIRMED`; из `COMPLETED`/`CANCELLED` переходов нет
6. Нельзя изменять/удалять запись в статусе `COMPLETED`
7. Нельзя сохранить запись без указания варианта услуги

**Клиенты/мастера (`ClientService`):**
1. Имя и телефон обязательны при создании клиента
2. Нельзя указать несуществующую роль
3. Нельзя сделать мастером того, кто уже мастер
4. Нельзя удалить клиента с активными (не завершёнными/не отменёнными) записями

**Каталог услуг (`ServiceCatalogService`):**
1. Нельзя создать услугу с несуществующим мастером
2. Нельзя создать услугу с несуществующим типом
3. Нельзя создать вариант услуги с ценой ≤ 0
4. Нельзя создать вариант услуги для несуществующей услуги
5. Нельзя удалить услугу, у которой ещё остались варианты
